# Netflix Titles — Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python, Pandas, NumPy, Matplotlib, and Seaborn.

## Research Questions

1. How has the balance between Movies and TV Shows changed across release years?

2. Which countries contribute the most Netflix titles, and how does the distribution differ between Movies and TV Shows?

3. How do content ratings differ between Movies and TV Shows, and how do missing or unusual ratings affect the comparison?

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Includes

- Data cleaning
- Missing-value handling
- Feature engineering
- GroupBy analysis
- Data aggregation
- Country analysis
- Rating analysis
- Movie-duration analysis
- Outlier detection using IQR
- Correlation analysis
- Data visualization
